## Comment utiliser les KML dans Google My Maps

1. Ouvre **https://mymaps.google.com** (compte Google connecté)
2. Clique **"Créer une nouvelle carte"** (bouton rouge en haut à gauche)
3. Dans le panneau de gauche, clique **"Importer"** sur le calque "Calque sans titre"
4. Upload le fichier `.kml` de la zone choisie
5. Les points apparaissent sur la carte avec l'ordre de visite + les détails (note, avis, promo, pitch hooks)
6. Tu peux renommer la carte ("Tournée Zone 1 - Vanves" par ex.)
7. La carte est **accessible sur ton mobile** via l'app Google My Maps ou Maps → Menu → "Vos lieux" → "Cartes"

## Alternative : lien direct Google Maps

Chaque fichier `.md` de zone contient un lien **"Ouvrir dans Google Maps"** qui ouvre directement l'itinéraire avec tous les points (sans import). Moins personnalisé mais instantané.
